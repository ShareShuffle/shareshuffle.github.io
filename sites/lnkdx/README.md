# LNKDX.COM

Static Firebase Hosting utility for safe LinkedIn public-profile shortcuts.

- `LNKDX.COM/RCWX` redirects to `https://www.linkedin.com/in/RCWX/`.
- Root page generates links, copy/share actions, and optional QR codes.
- Direct links have no ad interstitial.
- Homepage and error pages promote ShareShuffle.
- The destination host is hard-coded to LinkedIn public profiles, preventing open-redirect abuse.
- No profile scraping or LinkedIn content storage.

Firebase target: `lnkdx`
Expected Hosting site ID: `lnkdx`
Custom domains to connect in Firebase Console: `lnkdx.com` and optionally `www.lnkdx.com`.
