# Quit Stop (working name)

Installable Gracefeed web-app prototype for opening a user-approved SMS containing `STOP` or `QUIT` to a supplied nuisance-caller number.

## Product rules

- The name and domain are provisional.
- Never send a message automatically; the person must review and send it in Messages.
- Never claim that a keyword will stop every caller.
- Do not add accounts, analytics, contact uploads, or server-side number storage without a new privacy review.
- Preserve a no-database, device-local default.

## Local preview

Serve this directory over HTTP; service workers and clipboard access do not work reliably from a `file://` URL.
