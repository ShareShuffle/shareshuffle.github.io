# Founder Principles

1. **Build for decades, not trends.** Design should still feel good twenty years from now.
2. **Nothing important should exist only in chat.** Decisions belong in the repository.
3. **Authenticity beats synthetic polish.** Use real people, real stories, and honest context.
4. **Reduce friction.** Make the right action obvious and the safe action easy.
5. **Delight is a feature.** Warmth and personality can make useful software memorable.
6. **Prefer maintainability over cleverness.** Straightforward code and repeatable Bash win.
7. **Products inherit quality.** Shared improvements should benefit the whole portfolio.
8. **Every feature earns its place.** Preserve focus and resist accidental complexity.
