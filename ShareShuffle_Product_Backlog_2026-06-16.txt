RISKS / DECISIONS
- LLM features: Hold — No LLM API fees until revenue/support exists. Revisit: Revenue, grants, or very clear ROI.
- Server scraping Amazon/search pages: Avoid — Bot/dog-page/blocking/compliance risk; brittle. Revisit: Only if official API or user-authorized safe method exists.
- Extension changes while in review: Avoid — Compliance-only resubmission is safest. Revisit: Chrome rejects and asks for changes, or approval completes.
- ShelfMix public brand: De-emphasize for now — ShareShuffle + shfl.me is clearer during launch. Revisit: When shelf product identity needs separate brand.
- Social unfurl consistency: Improve but don't obsess — iMessage/social previews are inconsistent by platform. Revisit: Repeated failures after OG hardening.
- Blue hover selection mode: Later — High UX wow, but extension/content-script complexity and review sensitivity. Revisit: After chooser works and extension approval is stable.
- Affiliate links: Compliant and transparent — Revenue engine, but must never feel deceptive. Revisit: Review feedback or user confusion.
- Firestore/browser Firebase in public pages: Prefer server fetch endpoints — Avoid module/loading fragility on public routes. Revisit: Auth/user-owned write workflows mature.
