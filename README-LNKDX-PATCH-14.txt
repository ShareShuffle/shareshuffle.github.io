LNKDX.COM PATCH 14

Adds a standalone Firebase Hosting site and target named lnkdx.

Features:
- LNKDX.COM/RCWX -> linkedin.com/in/RCWX/
- All-caps LNKDX.COM brand treatment
- Profile URL/name converter on homepage
- Copy, Web Share, test-link, and optional QR-code actions
- Instant direct profile redirect with no ad interstitial
- ShareShuffle promotion on the homepage and invalid-link screen
- Hard-coded LinkedIn /in/ destinations to prevent open redirect abuse
- No profile scraping or storage
- Independent-service trademark disclaimer
- Responsive, polished one-page design

After applying this patch, run DEPLOY-LNKDX-PATCH-14.command.
Then add lnkdx.com as the custom domain in the Firebase Hosting console for site lnkdx.
