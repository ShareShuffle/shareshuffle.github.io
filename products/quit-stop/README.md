# Quit Stop (working name)

Gracefeed product experiment for a very small installable web app that helps a person prepare an SMS opt-out keyword after a nuisance call.

## Current product

- Source: `sites/quit-stop/`
- Working name: Quit Stop
- Final brand and domain: undecided
- Provisional host: `https://gracefeed-quitstop.web.app/`
- Firebase target: `quitstop` → Hosting site `gracefeed-quitstop`
- Persistence: none
- Authentication: none
- Analytics: none initially

## Core journey

1. Enter or paste the caller's phone number.
2. Choose `STOP` or `QUIT`.
3. Review the prepared message in the phone's Messages app.
4. Send it manually, then separately block the caller if desired.

The app must not claim to send automatically, access iPhone recents, block a number itself, or guarantee that an opt-out keyword stops every caller.
